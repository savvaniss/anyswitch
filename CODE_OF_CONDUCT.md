# Code of conduct

anyswitch is a technical project with contributors of every background and experience level. Everyone taking part in issues, pull requests, discussions and reviews is expected to:

- Be respectful and assume good faith. Critique code and ideas, never people.
- Keep discussions on topic and constructive. Explain decisions; do not dismiss questions.
- Welcome newcomers and AI-assisted contributions alike, judged by the same rules in [AGENTS.md](AGENTS.md).
- Respect the project's legal boundaries. Do not share game files, keys or instructions for obtaining them, and do not pressure others to.

Not acceptable: harassment, insults, discriminatory language, personal attacks, sharing someone's private information, and sustained disruption.

Maintainers may edit or remove content and restrict participation that breaks these expectations. Report problems privately to the maintainers through the contact on the repository owner's GitHub profile.
